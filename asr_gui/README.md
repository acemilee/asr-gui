# 本地长视频转写工具（GUI）

把本地音视频转成带时间戳的中文文字，10 小时级的整片也扛得住，**全程离线**，不调任何云端接口。

## 目录内容

| 文件 | 作用 |
| --- | --- |
| `app.py` | tkinter 图形界面（唯一入口） |
| `engine.py` | 转写引擎：分块解码、VAD、识别、标点、增量落盘、断点续跑、可取消 |
| `models_registry.py` | 8 档模型清单、缓存状态探测、手动目录校验 |
| `downloader.py` | 镜像/官方双源流式下载（`.part` 续传 + 体积校验） |
| `config.py` | 用户配置读写、缓存目录探测 |
| `run.bat` | 纯 ASCII 启动器：找解释器 + 预检依赖 + 用 `pythonw` 起界面 |
| `启动转写GUI.bat` | 双击入口，内部 `call run.bat` |
| `config.local.bat` | 本机配置（解释器路径、已有模型缓存位置），**不入库** |
| `GUI界面.png` / `GUI模型下拉.png` | 界面截图 |

## 怎么用

1. 双击 `启动转写GUI.bat`；或命令行：
   `..\VideoToNo-1.4.6-portable\venv\Scripts\python.exe app.py`
   （必须是装好依赖的解释器：`sherpa_onnx`、`av`、`numpy`、`faster_whisper`）
2. 选 **模型**（下拉共 8 档，后面直接标出「已缓存 / 未缓存·需下载约 X MB」）：
   - 已缓存的档位选上就能直接跑；未缓存的点 **下载模型**（默认走 hf-mirror，可切官方）；
   - 硬盘上已有模型目录时，点 **定位/导入…** 指过去即可，校验通过就当成已缓存。
3. 选 **音频文件**、**输出目录**、**文件名**，点 **开始转写**。
4. 结束得到两个文件：
   - `<名字>.txt` —— 人读版，每行 `[HH:MM:SS] 正文`；
   - `<名字>.jsonl` —— 机器版，每行一个 JSON 段（`start` / `end` / `text`），**断点续跑靠它**。

## 断点续跑

中途关窗、休眠、断网都不怕：重新打开同一输出目录、同一文件名点「开始转写」，检测到已有
`<名字>.jsonl` 会弹窗问你：**是** = 接着写；**否** = 清空重来；**取消** = 不转写。

## 模型怎么选

| 档位 | 设备 | 说明 |
| --- | --- | --- |
| `paraformer-zh`（默认） | 仅 CPU | 中文长视频首选；本机实测 **10 小时整片 64.8 分钟**，自带标点 |
| `base` / `small` | CPU / CUDA | 轻量；base 快但错字更多（"我心中一动"会认成"我心中一洞"） |
| `turbo` / `belle-turbo-zh` | CPU / CUDA | 体积与精度折中，belle 是中文微调版 |
| `large-v3` | CPU / CUDA | 最准也最大（约 3.1 GB） |
| `tiny` / `medium` | CPU / CUDA | tiny 用来验证链路；medium 中文不如上面几档 |

线程数默认 8；本机 24 核，冷机切片 8 线程 RTF 0.028、16 线程 0.026，差别不大，但**长时间连续跑会因笔记本
降频变慢**（同一切片冷机 0.026 → 满载 65 分钟后 0.08~0.10），所以按整片实测值估算：
**每 10 小时音频 60–70 分钟**（本次用 threads=16）。

## 注意

- **不要**把 10 小时的稿子丢回原来那个 App 的「LLM 笔记」阶段：它按 6500 字切块、单请求 300 秒且无任务级
  超时，几千段请求会把界面卡死。
- `paraformer-zh` 的 ONNX 带 `fsmn_block`（流式结构），**只能用 CPU**，选中即锁死设备。
- 配置存在 `%APPDATA%\asr-gui\config.json`；模型默认缓存在 `%APPDATA%\asr-gui\models`，可用环境变量
  `ASR_GUI_MODEL_DIR` 指到别的盘。
- 未捕获的异常会写进仓库根 `logs/error-<日期>.log`，不会静默消失。
